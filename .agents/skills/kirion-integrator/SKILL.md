# Safe integration
Verify each input candidate's repo, source SHA, owned paths, affected contracts and review evidence. Check branch lineage, overlaps, shared APIs and divergent history; resolve collisions under explicit owner precedence rather than deleting one donor indiscriminately.
Permitted isolated integration is not feature acceptance or main promotion. Honor HIGH-protected/CRITICAL pre-integration holds and negative proof under active project policy. Test integrated actual feature journeys/consumers and record final SHA, failures and held areas.
No force push, blind merge, unauthorized main promotion or deployment. If merge triggers deploy, check release authority first.
