# Financial Integrity

Protect exact money precision, actual supplier/tenant boundaries, lifecycle and stored financial ledger. Trace trigger → authorized actor → state transition → persisted postings → receipt/report → retry/restart. Denied/replay/concurrent paths matter. Never infer cleared money from a self-reported date.
