# Origin vs Work Mode

**Two independent axes:** codebase origin GREENFIELD/BROWNFIELD/UNKNOWN and current work mode DISCOVERY/IN_FLIGHT/MAINTENANCE/RECOVERY/PAUSED/UNKNOWN. A join context such as TAKEOVER is not a third origin or approval state.

GREENFIELD + DISCOVERY → [[Greenfield and Discovery]].
BROWNFIELD + IN_FLIGHT → [[In-Flight]] and [[Brownfield In-Flight]].
Existing defect → [[Maintenance]]. Incident → [[Recovery]]. Dormant or inherited → [[Paused and Takeover]].
