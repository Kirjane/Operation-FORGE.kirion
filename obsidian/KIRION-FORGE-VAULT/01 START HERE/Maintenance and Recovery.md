# Maintenance and Recovery

Maintenance preserves previously accepted behavior and tests the narrow regression: [[Maintenance]] → [[Kirion Debug]]. Recovery preserves backups, licenses, logs and persistent data: [[Recovery]] → [[Kirion Runtime]] → [[Controlled Recovery]].

Client data and machine licenses may never be reset without explicit authority. Use actual host proof; source tests alone are not installed-host QA.
