# Specialist Selection

In GitHub-connected ChatGPT sessions start with [[Kirion Core]], [[Kirion Dispatch]] and [[Kirion Session Host]]. Then select 1–3 applicable work specialists unless distinct risks require more.

- Financial: [[Kirion Business Logic]], [[Kirion Security]], [[Kirion QA]].
- Frontend-only showcase: [[Kirion Frontend]], [[Kirion QA]]; simulated roles do not create real authentication.
- Code defect: [[Kirion Debug]], [[Kirion Worker]].
- Windows installer or data/license restoration: [[Kirion Runtime]], [[Kirion Security]].
- Inherited/stale project state: [[Kirion Cognition]], [[Kirion Evidence]].
- Frozen candidate independent review: [[Kirion Review]] and relevant risk specialist.

The target project's accepted policy outranks generic skill guidance.
