# Honest evidence
For material claims identify status, source and observed time when relevant. Use repo@SHA, actual command/test exit, environment and artifact ref. Separate CODE_INSPECTED, TESTED, RUNTIME_OBSERVED, APPROVED, REPORTED, UNKNOWN, NOT_RUN, BLOCKED.
Never invent SHAs, paths, reviewers, accounts, GitHub CI, screenshots, performance improvements or user approval. A historical One Talibon field failure is evidence of the old work; it does not automatically measure a new FCI scorer's improvement.
Deliver compact outcome, changed paths, checks, risks and next necessary action. Link durable records instead of repeating entire chat histories.
