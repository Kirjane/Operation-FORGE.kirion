# ChatGPT-First Bootstrap

The following is a **prompt convention**, not a command, automatic plugin install or identity/permission grant.

~~~text
KIRION FORGE — BOOTSTRAP
Role: MAINTAINER
Target: <owner/repo or NEW_PROJECT>
Project origin: AUTO
Work mode: AUTO
Goal: <one verifiable user-visible outcome>
Action: RECONCILE_AND_PROCEED_WITHIN_AUTHORITY
~~~

The worker verifies GitHub login and source SHA, reads the actual issue/PR, identifies GREENFIELD/BROWNFIELD separately from DISCOVERY/IN_FLIGHT/MAINTENANCE/RECOVERY/PAUSED, loads [[Kirion Core]], [[Kirion Dispatch]], [[Kirion Session Host]] and relevant specialists, and executes only within actual authority.

Go to [[Greenfield Project]], [[Brownfield In-Flight]] or [[Maintainer Bootstrap]].
