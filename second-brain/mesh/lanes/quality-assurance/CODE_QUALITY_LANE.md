# Code Quality Lane

This lane defines quality as correctness, readability, bounded change cost, reviewability, testability, defensive behavior, and explicit state/authority rather than stylistic polish.

## Naming review

Apply the integrated Forge root [semantic naming rule](../../../../AGENTS.md#semantic-naming-and-readability) through normal writer and reviewer activation. Use Naming and Intent for guidance. Inspect actual introduced/renamed paths and identifiers, stable responsibility, duplicates and compatibility; material introduced violations require `FIX_REQUIRED` under Forge review. Do not expand scope to legacy cleanup or equate this check with acceptance.
