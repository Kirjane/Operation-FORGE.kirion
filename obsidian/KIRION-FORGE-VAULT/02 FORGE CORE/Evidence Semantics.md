# Evidence Semantics

Different evidence states must not be conflated: CODE_INSPECTED, TESTED, RUNTIME_OBSERVED, APPROVED, REPORTED, UNKNOWN, NOT_RUN and BLOCKED.

A passed CI workflow is not a Windows installed-host test, a source review is not acceptance or deployment, and a remembered SHA is not current Git truth. Cite executed commands, environment, exit code, relevant negative cases and artifact source.
