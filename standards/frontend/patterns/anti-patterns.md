# Anti-pattern catalog
See [register](../provenance.md) for project origins. Prohibitions target failure mechanisms, not particular libraries.

| Reject | Why | Corrective decision |
|---|---|---|
| Generic dashboard substitution, banners before work, ornamental badge soup | Product intent lost; low work visibility (D1–D3) | Rebuild around operator task, domain language, reference and design grammar |
| Color copied without semantic roles; conflicting cross-platform palettes | Contrast and identity drift (V1) | Role pairs, theme specimen, approved brand reconciliation |
| Chronological CSS overrides, utility hijacking, deletion without consumers | Navigation-order regression and broken secondary routes (V3) | Predictable cascade, consumer migration and scoped bridge |
| Drawer/modal without focus or true open check; viewport-only breakpoint | Clipping, inaccessible or lost details (I1/R1) | Actual content width, overlay semantics and keyboard proof |
| Shipped legacy default with beautiful unmounted new UI; wrong sibling app tests | False progress (A1/A3) | Real launcher-to-tree trace and integrated outcome |
| Global loader for unrelated modules; refresh unmount | One denied module destroys others or drops work (A2) | Local states, preserved mounted data, stale handling |
| Client permission fallback, fabricated official records/downloads, zero for redaction | Unauthorized or false truth (P1/P2/P4) | Server enforcement and explicit provenance, no synthetic production authority |
| Regenerate IDs or timestamps on retry; local lock treated as server authority | Duplicates/conflicts and replay (P3) | Stable payload, server idempotency, scoped recovery, tested fallback |
| Claim mocked adapter/axe/regex/build alone as product acceptance | Wrong oracle (E1/E2) | Tier labels, discriminating real interaction, platform evidence |
| Blanket framework change, all-skill loading, arbitrary file-length mandate | Cost, stale instructions, artificial fragmentation (W1/A2) | Proportionate vertical slices, task-selected skills, cohesion |
| Hiding legitimate UI because backend is missing; preserving old tree solely for tests | Goal substitution (D1/A3/E2) | Preserve approved product intent, surface backend dependency and reconcile oracle |
| Debug vocabulary on nontechnical operator surfaces | Cognitive burden and unclear actions (D3) | Domain copy; keep necessary technical terms for actual technical users |
